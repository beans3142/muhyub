# 캐릭터 그림 (92장)

`art/roster.json`의 92명을 모두 그렸다. 명세는 `tools/art_roster.py`에서 만들고, 그림체는 `art/prompts-sample.md`의 개정 4(한국 무협 웹툰풍, 투명 PNG)를 따른다. 묶음별 한눈 보기는 `_sheet_A.png`(플레이어 30), `_sheet_B.png`(출신·생업 32), `_sheet_C.png`(세력 30)이다.

## 파일

- `ID.png` 한 장에 인물 하나가 들어 있다. 배경은 투명하고, 인물 둘레에 6px 여백을 두고 잘랐다.
- 77장은 ChatGPT가 만든 원본 PNG(1254px 정사각형, 투명)를 그대로 받아서 잘랐다. 그래서 세로가 약 1250px이다. C19만 원본이 1024×1536이라 세로 1519px이다.
- 15장(A01~A08, B11, B24, C01, C10)은 처음 세션에서 흰 바닥과 검은 바닥 위의 화면 캡처 두 장으로 투명도를 되살린 것이다(`tools/art_matte.py`). 세로가 약 740px이고, 원본보다 선이 조금 무르다. 원본은 각 채팅에 남아 있어서 나중에 같은 방법으로 받아 바꿀 수 있다.
- 92장을 합치면 약 83MB다.

## 다시 만들거나 고친 것

| ID | 무엇이 문제였나 | 어떻게 했나 |
|---|---|---|
| B12, B25, B30 | 명세에 성별이 없어서 여성 배역(상인·여, 군관·여, 도둑·여)이 남자로 나왔다 | 모든 프롬프트에 성별을 넣도록 `tools/art_roster.py`를 고치고, 이 셋을 다시 그렸다 |
| A12 | "willowy" 14세 소녀 명세가 콘텐츠 정책으로 거절됐다 | 옷차림을 단정하게 고쳐 쓴 문장으로 다시 요청했다(로스터 문구는 그대로) |
| C16 | 16세 암살자 견습(마스크, 역수로 쥔 단검) 명세에 ChatGPT가 세 번 응답하지 않았다 | 20세 암중 세력 입문자, 허리에 칼집에 든 짧은 칼로 바꿔 로스터에도 반영했다 |

`roster.json`의 프롬프트는 이제 `Character (a man): …`, `Character (a woman): …`, `Character (a boy/girl): …`로 시작한다(`sex` 필드도 추가). A·B 묶음은 이름표의 남/여에서, C 묶음은 `C_FEMALE` 목록에서 성별을 정한다. 18세 미만이면 boy/girl로 쓴다.

## 남은 문제

- 위 15장은 해상도가 낮다.
- ChatGPT 쪽 채팅이 카테고리마다 하나가 아니다. 대화 다시 불러오기가 "Too many requests"로 막혀서 남은 몫을 "(이어서)", "남은 것" 채팅에서 만들었다. 채팅 제목 일부는 진행 표시가 실제와 맞지 않는다.
- 성별을 넣은 새 문구로 만든 것은 B12, C05, C09, C12, C15~C18, C27~C30 열두 장이다. B25, B30은 앞에 "female"을 붙인 문구로 만들었고, 나머지는 성별 표기가 없던 예전 문구로 만들었다. 그림은 모두 명세(나이·성별·소품)와 맞는지 하나씩 눈으로 확인했다.
