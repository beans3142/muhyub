작성 2026-11-24, 개정 1(판정을 d100으로 바꿈: 입문 시험·승진 DC와 보정은 1단계 개정 3 척도). 상태: 초안(검토 대기). 앞 단계: `docs/p1-combat.md`, `docs/p2-traits-realms.md`, `docs/p3-arts.md`. 근거: `lore.md`(세계관 정본·세력 시뮬레이션), 나무위키 「문파」「사형제 명칭」「장문인」「무림맹」「사도련」「개방」「표국」「무림의 세력」 틀과 개별 세력 문서, `docs/research-community.md` 4장(세력)·6장(한중월야 마도관 시험).

## 3. 안에서의 자리: 배분, 제자 등급, 직위

문파 안에서 한 사람의 자리는 세 가지로 정해진다. 나무위키 「사형제 명칭」 기준이다.

### 3-1. 배분(항렬)

장문인의 제자가 일대제자, 그 제자가 이대제자다. 배분은 입문할 때 스승의 배분 + 1로 정해지고 바뀌지 않는다. 나이와 상관없다. 늙어서 입문하면 어린 사형을 모셔야 하고, 은거한 노고수의 말년 제자로 들어가면 중년 제자들과 같은 배분이 된다. 불가·도가 문파는 배분마다 돌림자를 정하고, 입문하면 스승이 돌림자를 넣은 법명·도호를 지어 준다(`data/names.js`의 이름 갈래가 바뀐다). "현(玄)자 배" 식으로 부른다.

배분이 쓰이는 곳은 셋이다. 호칭과 존대(3-5), 직위 승진의 하한(장로는 대개 장문인보다 한 배분 위이거나 같은 배분), 그리고 인연 사건(사형제 갈등, 사숙의 시기).

### 3-2. 제자 등급

| 등급 | 뜻 | 배우는 무공 | 대개의 경지 |
|---|---|---|---|
| 입문제자 | 막 들어온 아이. 잡일과 기초 | 삼류 기초 심법·초식 | 범인~삼류 |
| 평제자 | 기초 무공 수련 중 | 삼류 | 삼류 |
| 내문제자(정식제자) | 본산에서 먹고 자며 배운다 | 이류 | 삼류~이류 |
| 진산제자 | 본산에 남아 핵심 무공을 받는다 | 일류 | 이류~일류 |
| 직전제자(적전제자) | 스승의 진전을 잇는 후계 | 상승, 스승의 비전 | 일류~절정 |
| 대제자(장문제자) | 다음 장문인으로 정해진 제자 | 절세 | 절정 이상 |
| 속가제자 | 문파 밖에서 배우고 하산한다. 가문이 기부금을 낸다 | 삼류~이류, 비전 불가 | 삼류~이류 |

속가제자는 하산 뒤 문파 이름을 빌려 일하고, 크면 속가 문파(○○파 ○○분원)를 세운다. 아미·소림처럼 계율이 엄한 문파의 여제자·남제자가 혼인하려면 속가로 남는다(나무위키 「문파」).

### 3-3. 직위

직위는 문파를 움직이는 자리다. 제자 등급과 따로 오른다. 사다리마다 단계와 대개의 경지를 둔다. 경지 대응은 나무위키 「경지」의 위상 서술(일류 = 대문파 당주·장로급, 절정 = 장문인·원로급)과 한중월야 천마신교의 마도관 시험(하·중·상급 무사 = 삼류~일류, 대주 = 절정, 단주 = 초절정, 장로 = 화경)을 섞었다.

| 사다리 | 단계 (낮은 → 높은) | 수장의 다른 이름 |
|---|---|---|
| 문파(sect) | 제자(3-2) → 각주·당주(장경각주, 계율당주, 외당주 등) → 장로 → 태상장로 → 장문인 | 소림 방장, 무당 장교, 아미 사태 |
| 세가(clan) | 방계·가솔 → 직계 → 가주 후보(소가주) → 원로 → 가주 | 태상가주(물러난 가주) |
| 무림맹(league) | 맹원 → 조장 → 대주 → 단주 → 각주·당주 → 군사 → 부맹주 → 맹주, 그리고 봉공(장로급 객원) | 맹주는 회의로 추대 |
| 마교(demon) | 교도 → 하·중·상급 무사 → 대주 → 단주·향주 → 호법(좌·우) → 장로 → 부교주 → 교주 | 천마 |
| 사파 연합·녹림·수로채(bandit) | 졸개 → 조장 → 두목 → 부채주 → 채주 → 총채주 | 녹림왕, 수왕, 련주 |
| 개방 | 1결 ~ 8결(매듭 수). 6결 장로, 7결 후계, 8결 방주 | 방주 |
| 정보·생업 방회(info) | 심부름꾼 → 정보원 → 분타주 → 총관 → 문주 | 하오문주 |
| 살수(assassin) | 견습 살수 → 살수 → 청부 조장 → 살주 → 막주 | 문주는 이름을 버린다(무명) |
| 암중(shadow) | 말단 → 행동대 → 간부 → 장로 → 수뇌 | |
| 관부(guard) | 소기 → 총기 → 백호 → 천호 → 지휘사 | 동창·서창은 환관 직위 |
| 표국 | 쟁자수 → 표사 → 표두 → 부국주 → 국주 | |

**직위와 경지의 대응(대문파 기준).**

| 직위 | 대개의 경지 | 승진 조건 |
|---|---|---|
| 각주·당주 | 일류~절정 | 진산제자 이상, 공적, 경지 일류 |
| 장로 | 절정~초절정 | 배분, 공적, 경지 절정 |
| 태상장로 | 초절정~화경 | 물러난 장로·장문인 |
| 장문인 | 절정~화경 | 대제자 또는 장로 회의 추대. 무공보다 인품·정치·배분이 중요해 문파 최고수가 아닐 때가 많다(나무위키 「장문인」) |

작은 세력은 이 표에서 한두 단계씩 낮다(중소 문파 장문인 = 일류). 사파·마교·흑도는 "제일 센 자가 우두머리"라 경지 조건이 한 단계 높고 배분은 보지 않는다.

**승진 판정.** 해마다 다음 직위의 조건(경지·배분·제자 등급)을 채웠으면 판정한다. `d100 + 공적/2 + 명성 보정 + 인연 보정(수장·장로 호감) ≥ DC(직위 단계 × 15 + 위상 × 10)`. 자리가 비어야 오를 수 있는 직위(장문인·가주·맹주·교주)는 수장의 죽음·은퇴 사건 때만 판정한다. 마교·사파는 도전(비무·암살)으로 자리를 빼앗는 길이 있다.

### 3-4. 무공 접근

직위·제자 등급이 오를 때 배울 수 있는 무공 등급이 열린다. 한중월야 마도관 시험 구조(시험을 통과할 때마다 비급 서재 한 층이 열린다)를 따랐다.

| 자리 | 열리는 무공 |
|---|---|
| 입문·평제자 | 삼류 |
| 내문제자 | 이류 |
| 진산제자·각주 | 일류 |
| 직전제자·장로 | 상승 |
| 대제자·장문인·태상장로 | 절세, 신공 |

**공적(기여도).** 문파 일(순찰, 표행 호위, 임무, 비무 우승, 적 처단)로 공적을 쌓는다. 공적을 써서 열린 등급 안의 무공을 고르고, 비급각(장경각·장서각) 열람 기간을 산다. 열람 기간이 짧으면 성취 상한이 낮은 채로 익힌다(비급 해독 판정, 3단계 7장).

### 3-5. 호칭

인연(6단계)과 사건 문장에 쓴다. 사부·사모, 사형·사저(먼저 들어온 이), 사제·사매(나중에 들어온 이), 대사형, 사백(사부의 사형)·사숙(사부의 사제)·사고(사부의 사저·사매), 사조(사부의 사부), 사질(사형제의 제자), 사손(제자의 제자). 배분이 높으면 나이가 어려도 존대받는다.

| 사파·흑도 | 배신 금지, 상납 | 처단 |
| 살수 | 청부는 거절하지 않는다, 정체 비밀 | 처단 |
| 모든 문파 | 비전 무공 무단 전수 금지 | 폐공·처단, 원수가 됨 |

계율을 어긴 일은 공적에서 빠지고 발각 판정(수읽기·명성)에 따라 벌이 정해진다.

## 6. 나가는 길과 겹치는 소속

| 길 | 조건 | 결과 |
|---|---|---|
| 하산 | 수련을 마침(속가는 언제든) | 좋은 관계로 남음. 문파 이름을 빌려 씀 |
| 파문 | 계율 위반 | 「낙인」 특성, 그 세력 평판 상한 −50, 무공 회수(폐공) 판정 |
| 배신·탈주 | 다른 세력으로 감 | 원수가 됨. 사파·살막은 추격 사건 |
| 멸문 생존 | 세력이 멸문 | 복수·재건 갈래, 개파조사 엔딩 길 |
| 봉문 | 세력이 문을 닫음 | 폐관하거나 하산 |
| 은퇴 | 고령 | 태상장로·원로 |

**겹치는 소속.** 문파 속가제자이면서 표국 표사, 세가 방계이면서 무림맹 맹원은 흔하다. 그러나 정파 문파와 마교·암중 세력은 겹칠 수 없고 몰래 겹치면 「첩자」 상태가 되어 해마다 발각 판정을 한다.

### 7-2. 숙적과 동맹 (정본에서 시작, 생마다 달라질 수 있음)

| 관계 | 세력 |
|---|---|
| 숙적 | 화산 ↔ 종남(같은 섬서), 남궁 ↔ 서문, 하북팽가 ↔ 황보세가, 제갈 ↔ 사마, 무림맹 ↔ 사도련, 정파 ↔ 천마신교, 대뢰음사 ↔ 소뢰음사, 북해빙궁 ↔ 대막태양궁(정반대 성질), 남만 야수궁 ↔ 혈교(땅 다툼) |
| 동맹 | 무림맹 회원(구파일방·오대세가), 사도련 회원(흑도), 소림 ↔ 무당(정파 양대 기둥) |

숙적 쌍은 나무위키 개별 세력 문서(화산·종남, 황보세가·하북팽가, 제갈·사마, 대뢰음사·소뢰음사, 태양궁·북해빙궁, 남만야수궁·혈교)에서 확인한 구도다.

### 7-3. 개인과 세력

플레이어는 세력마다 평판(−100~100)을 따로 가진다(6단계). 소속 세력의 숙적에게는 평판이 −30에서 시작한다. 세력의 원한은 사람에게 이어진다. 내가 죽인 사람의 문파는 원수가 되고, 그 문파의 동맹도 평판이 깎인다.

## 8. 군소 문파

세상에는 이름 있는 103곳 말고도 지역마다 작은 문파·무관·방회가 많다. 엔진이 필요할 때(출신, 사건, 세력 분열) 만든다.

- 이름 = 지명 한두 글자(근거지의 성·현·산) + 유형 접미. 접미는 검문·도문·권문·창문, 무관, 도관(도가), 사(절), 방·회(방회), 채(산적), 표국, 상단, 장(장원)이다. 예: 남양검문, 청하무관, 운산도관, 흑풍채, 진원표국.
- 위상 1, 규모 수십 명, 생마다 수명 20~80년. 수장은 일류 안팎.
- 무공은 공용 무공(`data/arts.js`의 무소속)에서 삼류~일류 5~10개를 골라 대표 무공으로 삼는다.
- 세력 분열(`lore.md` 5장)로 생긴 새 세력은 모 세력의 무공 일부와 숙적 관계를 물려받는다.
- 플레이어가 개파하면 군소 문파로 시작한다(개파조사 엔딩 길).

## 9. 수장이 되었을 때

플레이어가 장문인·가주·맹주·교주·채주가 되면 세력의 결정이 선택지로 넘어온다: 제자 받기(입문 시험 난이도), 무공 전수와 창안 무공 등록, 외교(동맹·화친·선전포고), 봉문, 무림맹·사도련 가입과 탈퇴. 세부는 7단계(사건)와 8단계(세계 시뮬레이션)에서 정한다.

## 10. 데이터

세력 정본은 `data/factions.js` 하나다(103곳). 예전 `world.js` FACTIONS·LADDERS와 `tools/faction_styles.js`는 여기로 합치고 지웠다. 무공 생성기(`tools/gen_arts.js`)와 출신 생성기(`tools/gen_origins.js`)가 이 파일을 읽는다.

| 값 | 내용 |
|---|---|
| `FACTIONS` | 세력마다 1장 스키마(계열·성향·종교·사다리·근거지·위상·규모·입문·계율·무공 생성 설정) |
| `LADDERS` | 3-3의 사다리 11종(문파·세가·무림맹·마교·녹림류·개방·정보 방회·살수·암중·관부·표국) |
| `DISCIPLE`, `ART_ACCESS` | 제자 등급과 자리별로 열리는 무공 등급(3-2, 3-4) |
| `RELATION`, `RIVALS`, `ALLIES`, `ALLIANCE_MEMBERS` | 7장의 기본 관계·숙적·동맹·연합 회원 |
| `MINOR_SUFFIX` | 8장 군소 문파 이름 접미 |

새외 5곳(포달랍궁·북해빙궁·남만 야수궁·천축 무승·동영 검객)의 세력 기록을 새로 만들었다. 출신표는 세력 규모에 비례하게 가중치를 줄여, 세력 출신으로 태어나는 비율이 21% 안팎이 되게 했다(출신 672종).

## 11. 이 단계가 여는 갈래

- 같은 문파 안에서도 입문제자로 늙는 사람, 속가로 하산해 표국을 차리는 사람, 직전제자가 되어 장문인 자리를 다투는 사람이 갈린다.
- 배분이 나이와 따로 놀아서, 늦게 입문한 노인이 어린 사형을 모시거나, 은거 고수의 말년 제자가 갑자기 장로들과 같은 배분이 되는 사건이 생긴다.
- 공적을 쌓아 비급각을 여는 수련 경로가 생긴다.
- 파문·배신·멸문 생존이 다른 세력으로 가는 문이 된다. 사파로 떨어지거나, 군소 문파를 세운다.
- 숙적 구도가 출신과 소속에 따라 원한 사건을 부른다.

## 12. 다음 단계로 넘기는 것

- 5단계: 표국·상단·의가·관부처럼 생업과 겹치는 세력의 생업 사다리.
- 6단계: 명성·악명·세력 평판 수치, 사형제·사부 인연.
- 7단계: 입문 시험, 승진, 파문, 첩자 발각, 수장 교체 사건.
- 8단계: 세력 시뮬레이션(무력·재력·결속·영역) 수치와 군소 문파 생성 빈도.

## 13. 확인하지 못한 것

- 개방 매듭 수는 출처마다 다르다(나무위키 「문파」는 8결 방주, 「무협물/용어」는 "구결: 개방 방주"). 8결로 두었다.
- 직위별 경지 대응은 나무위키 「경지」 한 문서와 한중월야 마도관 시험 구조를 섞은 설계값이다.
- 기본 관계 수치와 승진 DC는 설계값이라 9단계에서 맞춘다.
